## Qシリーズは何を検知しますか？

Qシリーズは人物を検知し、設定した警報範囲への接近を知らせます。カメラ・モニター・ブザーを組み合わせて、運転者の安全確認を支援します。

- [車両用AIカメラ・人物検知による事故防止支援｜株式会社INBYTE](../uses/vehicle-person-safety.md)

<a id="faq-054"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：どんな姿勢の人でも認識できますか？

立っている人、しゃがんでいる人、後ろ姿の人、身体の一部が隠れた人など、さまざまな姿勢の人物を検知します。隠れ方や設置環境によっては検知できない場合があるため、目視確認と併用してください。

<a id="faq-055"></a>

## Qシリーズの各モデルの違い（カメラ数・モニターサイズ）は？

QX：4カメラ／9インチモニター。Q7：4カメラ／7インチモニター。Q4：2カメラ（左右・赤外線LED搭載）／7インチモニター。Q5：1カメラ／7インチモニター。

- [フォークリフトの人への接近を検知したい](../uses/forklift.md)

<a id="faq-056"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：各モデルのセンサー画素数はどれくらいですか？

センサーは200万画素（QX/Q7）または100万画素（Q4/Q5）CMOSです。

<a id="faq-057"></a>

## QXとQ7の違いは何ですか？

QX・Q7は4カメラ・200万画素・対角175°のカメラ構成で、録画に対応します。QXは9インチ・1280×720、Q7は7インチ・800×480のモニターです。QXは大きな画面で確認したい場合、Q7は設置スペースを抑えたい場合の候補になります。

- [QX 人身事故防止AIカメラ](../products/qx.md)
- [Q7 人身事故防止AIカメラ](../products/q7.md)

<a id="faq-058"></a>

## Q4の特徴は何ですか？

Q4は赤外線LEDを搭載した2カメラ構成です。検知する方向は設置位置に応じて確認します。本体録画機能はありません。

- [Q4 人身事故防止AIカメラ](../products/q4.md)

<a id="faq-059"></a>

## Q5の特徴は何ですか？

後方をカバーする1カメラモデルで、フォークリフト構造上死角になりやすいカウンターウエイト後方の作業者を、広角カメラ（水平角度112度）で検知します。

- [Q5 人身事故防止AIカメラ](../products/q5.md)

<a id="faq-060"></a>

## QX・Q7に録画機能はありますか？

QX・Q7はmicroSDカードへの録画に対応します。Q4・Q5には本体録画機能がありません。Q7は同梱64GBで約8時間、最大256GBのmicroSDカードに対応します。録画時間は条件によって変わります。

- [録画を安全活動・KYT・環境改善・QC活動に活用する](../uses/safety-review.md)

<a id="faq-061"></a>

## AIカメラシステム QX/Q7：警報距離の設定はできますか？

警報距離はタッチパネルで約1.5m・3m・5m・7mから設定可能で、バックギア連動・ブレーキ連動にも対応します。

- [安全警告装置の鳴りすぎを抑える：AIカメラの警報範囲と車両信号](../uses/alarm-optimization.md)

<a id="faq-062"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：防水・防塵性能はどの程度ですか？

カメラはIP69K（Q7/QX）またはIP68（Q4/Q5）、モニター・ブザーはIP65対応で、過酷な作業現場でも使用できます。

<a id="faq-063"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：動作温度・保存温度はどの程度ですか？

動作温度は-20～70℃、保存温度は-40～85℃です。

<a id="faq-064"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：AIの検知精度はどれくらいですか？

自社評価（2024年5月時点）では、約97％以上の人物検知率です。これは所定の試験条件での結果であり、すべての設置環境で同じ検知率を保証するものではありません。

<a id="faq-065"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：誤検知や検知漏れはありますか？

明るさ、逆光、レンズの汚れ、遮蔽物、取付状態などが影響するため、未検知や誤検知が起こる場合があります。実際の環境で確認し、目視確認と併用してください。

<a id="faq-066"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：ソフトウェアアップデートによって何が良くなりますか？

AI検知アルゴリズムを更新し、誤検知の低減や検知精度の改善を継続しています。対象機種の更新内容や適用方法は、サポート窓口へお問い合わせください。

<a id="faq-067"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：アップデートは必須ですか？

必須ではありませんが、最新の検知性能を維持するため、サポート情報ページで公開されている最新ファームウェアの適用を推奨しています。

<a id="faq-068"></a>

## AIカメラシステム QX/Q7/Q4/Q5共通：作業中に警報音が大きすぎる・気になる場合の対処法は？

機種に応じてブザーシートによる減音や、オプションの音量調整ブザーへの変更をご案内できます。作業環境で必要な警報が聞こえるよう、取付店または株式会社INBYTEへご相談ください。

## QX／Q7：録画用microSDカードは定期的な交換が必要ですか？

microSDカードは繰り返しの書き込みで劣化します。定期的に録画・再生できることを確かめ、異常がある場合は取扱説明書に従って対応してください。交換するカードの対応仕様や交換時期は、サポート窓口へご相談ください。

## フォークリフト・建設機械の警報が鳴りすぎる場合、Qシリーズで調整できますか？

Qシリーズは、取り付け位置、警報距離、対応する車両信号との連動を現場に合わせて設定します。QX・Q7の警報距離は約1.5m・3m・5m・7m、Q4・Q5は約3m・5m・7mです。通常作業と危険な接近の両方で確認し、不要な警報を抑えながら必要な注意喚起が届く設定に調整します。検知結果は明るさ、遮蔽物、取り付け状態などで変わります。
