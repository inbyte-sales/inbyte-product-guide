## ミリ波レーダーとはどのような技術ですか？

電波の反射を利用して対象物の接近や距離を検知する方式です。対象のレーダー製品は24GHz帯を使用します。実際の検知結果は、対象物の形状・材質や設置条件によって異なります。

<a id="faq-077"></a>

## ミリ波レーダーは赤外線センサーとどう違いますか？

赤外線センサーには、熱の変化を捉える方式と、赤外光の反射・遮断を利用する方式などがあります。熱を捉える方式は周囲との温度差、光を利用する方式は遮蔽物や対象物の反射特性などが影響します。レーダーは電波を利用し、暗さや逆光の影響を受けにくいことが特長です。

<a id="faq-078"></a>

## ミリ波レーダーは超音波センサーとどう違いますか？

超音波センサーは音波、レーダーは電波を利用します。INBYTEのレーダー製品は、暗さや逆光の影響を受けにくく、RODS-MCは最大10m、RC-06C-ALL・RODS-RL6は最大5.5mの接近検知に対応します。実際の検知範囲は対象物や取り付け条件によって変わります。

<a id="faq-079"></a>

## RODS-MCはどんな仕組みで危険を検知しますか？

ミリ波帯域の電磁波を利用した高性能レーダーセンサーで周囲の物体を検知し、5段階の接近警報でアラートします。防水防塵IP69K、15G耐振動設計で悪天候・振動環境でも安定動作します。検知距離は最大10mです。

- [RODS-MC 接近警報レーダー](../products/rods-mc.md)

<a id="faq-080"></a>

## レーダーが対応する「悪天候」とは、どのような状況ですか？

雨、霧、雪、粉じんなどで見通しが悪い状況を指します。レーダーは電波で検知するため、暗さや逆光の影響も受けにくい方式です。ただし、すべての条件での検知を保証するものではありません。取り付け状態や対象物によって検知結果は変わるため、目視確認と併用してください。

- [RODS-MC 接近警報レーダー](../products/rods-mc.md)

<a id="faq-082"></a>

## RC-06C-ALLはRODS-MCと何が違いますか？

RC-06C-ALLはミリ波レーダー搭載カメラ（1080P SONY CMOS、赤外線LED付き）と7インチモニターがセットになったシステムで、3段階の接近アラームに加え高画質映像での状況確認ができます。検知距離は最大5.5mです。

- [RC-06C-ALL 接近警報レーダー](../products/rc-06c-all.md)

<a id="faq-083"></a>

## RODS-RL6の特徴は何ですか？

高性能レーダーとインジケーターを組み合わせた安全支援システムで、死角や後方の障害物・歩行者を検知し、距離に応じて警報パターンを変化させます。検知距離は最大5.5mです。

- [RODS-RL6 接近警報レーダー](../products/rods-rl6.md)

<a id="faq-084"></a>

## RODS-RL6の耐候性はどの程度ですか？

RODS-RL6のセンサーはIP69K・15G耐振動の仕様です。雨や霧、雪などの環境での使用を想定しています。インジケーターの設置条件はセンサーと異なるため、取扱説明書に従って設置してください。

- [RODS-RL6 接近警報レーダー](../products/rods-rl6.md)

<a id="faq-085"></a>

## RODS-RL6：検知範囲は調整できますか？

RODS-RL6は3種類の検知モードから選択できます。必要な距離・幅と作業動線を確認し、実車で警報範囲を確認して設定してください。

- [RODS-RL6 接近警報レーダー](../products/rods-rl6.md)

<a id="faq-087"></a>

## RODS-RL6：大型車両への取付けは可能ですか？

大型車両への後付けを検討できます。車幅、車体形状、取付位置、遮蔽物、必要な検知範囲を確認し、適切な構成を選定します。

<a id="faq-088"></a>

## RODS-MC/RC-06C-ALL/RODS-RL6共通：動作温度はどの程度ですか？

センサーの動作温度は、RODS-MC・RODS-RL6が−40～85℃、RC-06C-ALLが−30～85℃です。表示器やモニターの温度範囲は別途仕様をご確認ください。

<a id="faq-089"></a>

## RODS-MC/RC-06C-ALL/RODS-RL6共通：耐久性能はどの程度ですか？

対象レーダー製品のセンサーはIP69K・15G耐振動の仕様です。インジケーターやモニターの設置条件は、それぞれの仕様をご確認ください。

<a id="faq-092"></a>

## RODS-MC/RC-06C-ALL/RODS-RL6共通：操縦席からインジケーターの警報はどのように見分けますか？

警報の表示と音は機種によって異なります。RODS-MC・RODS-RL6のインジケーター、RC-06C-ALLのモニターについて、それぞれの警報段階と表示方法を取扱説明書でご確認ください。

## レーダーは人だけを識別できますか？壁や車両にも反応しますか？

レーダーは電波の反射を利用して物体を検知します。人物だけを識別するAIカメラとは機能が異なります。対象物の形状・材質や取り付け状態によって検知結果が変わります。
