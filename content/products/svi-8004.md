# SVI-8004 AIサラウンドカメラ

情報更新日：2026-09-15

車両周辺の人身事故防止を支援。SVI-8004は、前後左右4台のカメラで車両周囲を俯瞰表示し、人物の接近警報と録画を行うAIサラウンドカメラシステムです。トラック、重機、作業車、特殊車両の周囲確認を支援します。

製品・機種名：SVI-8004 AIサラウンドカメラ ｜ 分類：サラウンドカメラ

## こんな用途に

- [車両周囲を360度の俯瞰映像で確認したい](../uses/surround.md)
- [建設重機・作業現場の接触リスクを減らしたい](../uses/construction.md)
- [トラック・バスの側方と後方を確認したい](../uses/truck.md)
- [車両搭載AIカメラで人身事故防止を支援する](../uses/vehicle-person-safety.md)
- [録画を安全活動・KYT・環境改善・QC活動に活用する](../uses/safety-review.md)

## 主な機能・構成

- 合成した俯瞰映像と3D画面で周囲を確認。
- ウインカー・バックギア等の信号で表示を切り替え。
- 専用リモコンと別売タッチモニターによる操作に対応。

## 仕様・対応条件

| 項目 | 内容 |
| --- | --- |
| カメラ構成 | 前・後・左・右の4台 |
| AI検知対象 | 人物 |
| 表示 | 360度俯瞰、3D表示、運転状況に応じたビューモード |
| ECU入力 | 1920×1080 AHD ×4 |
| ECU映像出力 | HDMI／AHD／CVBS。HDMIとAHDは同時出力不可 |
| ECU電源 | 12V／24V（9～36V） |
| ECU消費電力 | 最大9.8W |
| ECU動作温度 | -25～75℃ |
| ECU保存温度 | -30～80℃ |
| ECU寸法・重量 | 150×23×100mm／約400g |
| カメラ | 1920×1080、1/3インチ CMOS、IP68 |
| カメラ寸法・重量 | 20×20×30mm／約41g（カメラのみ） |
| 録画仕様 | 1920×1080／25fps／MP4／H.265 |
| 記録媒体 | 別途USB記録媒体が必要。最大1TB |
| 別売モニター | 10.25インチ、1920×720、タッチ対応 |
| モニター入力 | HDMI、タッチ用USB |
| モニター電源・動作温度 | 12V／24V、-20～65℃ |

## 導入・使用条件

- 検知・警報で安全確認を支援します。検知性能は周囲の環境や取り付け状態によって変わります。運転者・作業者の目視確認と併用してください。
- 映像は合成されるため実際の距離感等とは異なる場合があります。取り付け位置と調整条件を確認してください。
- タッチ式モニターと録画媒体は別途選定します。保存時間は容量・録画条件により異なります。
