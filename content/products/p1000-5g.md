# LINKFLOW P1000 5G 遠隔映像共有カメラ

情報更新日：2026-09-15

P1000 5Gは、5G/LTE回線による現場映像の共有と双方向音声通話に対応します。建設現場の遠隔臨場や、保守点検時の遠隔支援に向けた製品です。

製品・機種名：P1000 5G ｜ 分類：業務用ボディカメラ

発売予定

## こんな用途に

- [現場映像を共有して遠隔支援したい](../uses/remote-support.md)
- [業務用ボディカメラの用途一覧：安全・教育・点検・接客・警備](../uses/body-camera.md)

## 主な機能・構成

- 現場と本部の映像・音声連携を支援。
- 複数現場の映像確認と運用管理を想定。

## 仕様・対応条件

| 項目 | 内容 |
| --- | --- |
| 提供状況 | 2026年秋発売予定 |
| モバイル通信 | 5G／LTE |
| 遠隔連携 | リアルタイム映像共有、双方向音声通話 |
| 表示 | 3.1インチタッチ液晶 |
| 管理機能 | マルチ画面監視、クラウド保存、GPS連携 |

## 導入・使用条件

- 2026年秋発売予定です。納期・提供条件はお問い合わせください。
- 通信・クラウド・管理システムの契約条件と、現場の通信環境を確認してください。
- P3000Aの標準機能とは異なるモデルとして選定してください。
