# LINKFLOW P3000D 専用クレードル

情報更新日：2026-09-15

P3000Dは、複数のボディカメラの充電と映像データ転送をまとめて行う専用4連クレードルです。PC・NAS・管理システムへのバックアップ運用を支援します。

製品・機種名：LF-P3000D ｜ 分類：業務用ボディカメラ

## 主な機能・構成

- ドッキング時の充電とデータ取り出しをまとめて運用。
- 管理用PC、拠点NAS、サーバー／Web統合管理を選定。

## 仕様・対応条件

| 項目 | 内容 |
| --- | --- |
| モデル名 | LF-P3000D |
| 充電台数 | 最大4台 |
| 有線LAN | 1GbE RJ45（1000Base-T） |
| データ転送 | 最大120Mbps |
| 充電時間 | 約3時間 |
| 動作温度 | 0～40℃ |
| 動作湿度 | 20～80%RH |
| 入力電源 | 100～240V AC、1.7A、50～60Hz |
| 消費電力 | 65W |
| 寸法・重量 | 400×52.4×83mm／476g |

## 導入・使用条件

- 対応カメラと接続先の要件を確認してください。カメラや保存先機器は別途構成します。
- 有線LANのリンク速度は1Gbps、データ転送速度は最大120Mbpsです。
- P1000 5Gとの互換性は、発売時の確定仕様を確認してください。
