# AVIS AI外観検査システム

情報更新日：2026-09-15

AVISは、製造ラインのキズ・欠け・異物・欠品などをカメラとAIで検査するシステムです。対象ワークや良否基準に合わせて、カメラ・照明・エッジPCとAIモデルを構成します。

製品・機種名：AVIS ｜ 分類：AI外観検査

## こんな用途に

- [製造ラインの外観検査をAIで自動化したい](../uses/inspection.md)

## 主な機能・構成

- 医薬品の亀裂や異物、繊維・フィルムの傷、食品の欠け・焦げ、金属部品のバリ・打痕などの外観検査に対応。
- 自動車部品の溶接漏れや欠品、印刷エラー等の用途も相談可能。
- 現場確認 → 機器選定・設置 → モデル学習と評価 → エッジPCへ実装 → 運用・保守。
- 新ワークへの再学習やモデル調整を継続支援。

## 仕様・対応条件

| 項目 | 内容 |
| --- | --- |
| 正式名称 | AI Vision Inspection System |
| 提供形態 | 機材・AIモデル開発・保守等を含む月額制 |
| カメラ解像度 | 2K～20MPの汎用カメラから選定 |
| カメラ台数 | 2～4台構成 |
| 照明・レンズ | 検査対象に合わせて個別選定 |
| エッジ処理 | 26 TOPsのAIエッジハンドラー |
| 学習工程 | オンライン接続で現場データを収集・学習・調整 |
| 検査運用 | エッジPCへの実装後は外部ネット非接続で運用可能 |
| 評価基準 | 顧客と事前合意した良否・見逃し・過剰検出等の条件で評価 |
| モデル作成期間 | AIモデル作成の目安：1.5～3か月。システム全体の導入期間は構成・検証内容に応じて調整します。 |

## 導入・使用条件

- 対象ワーク・撮影条件・処理速度を確認し、サンプルで適用評価を行います。
- 検査対象とラインの処理条件に合わせて、判定精度と処理時間を評価・調整します。
- 運用時の外部ネット非接続と、学習・更新時の接続要件を区別して構成します。
- 月額料金・税区分・最低利用期間・保守や追加費用の条件は個別にご案内します。
