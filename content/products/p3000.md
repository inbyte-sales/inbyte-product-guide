# LINKFLOW P3000 ボディカメラ

情報更新日：2026-09-15

P3000は、接客や警備、工事・点検の状況を装着者の視点で記録する業務用ボディカメラです。最大4K UHDの映像を記録します。

製品・機種名：P3000 ｜ 分類：業務用ボディカメラ

## 主な機能・構成

- 録画した映像を、状況の振り返りや作業記録に活用。
- 専用クレードル等を利用した充電・データ管理の構成を相談可能。

## 仕様・対応条件

| 項目 | 内容 |
| --- | --- |
| 最大録画解像度 | 4K UHD／30fps |
| 画角 | 148.2° |
| 重量 | 140g |
| 寸法 | 54.5×87.5×34.4mm |
| F値 | F1.8 |
| 内蔵メモリ | 64GB |
| 録画形式 | MP4／H.264 |
| 通信 | Wi-Fi／Bluetooth／GPS |
| 夜間撮影 | LED照明 |
| 防水防塵 | IP67 |
| 充電時間 | 約3時間 |

## 導入・使用条件

- 録画時間、画質、充電時間は設定・使用環境により変わります。
- ビーコン・管理機能等に必要な周辺機器と利用条件を確認してください。
- 映像の取り扱い、利用目的、閲覧権限を定めて運用してください。
